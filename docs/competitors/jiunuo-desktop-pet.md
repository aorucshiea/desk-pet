# 啾糯桌宠（nicedoctors / JiuNuoDesktopPet）

- 仓库/主页：https://github.com/nicedoctors/JiuNuoDesktopPet · 星标：58（fork 9）· C# / WPF / .NET 8（Win32 互操作）· 许可：PolyForm Noncommercial 1.0.0（代码非商业；角色素材授权仍未核清，主题非鸣潮官方）· 活跃度：2026-10-01 建库，最后 push 2026-10-05，最新 Release v1.3.3（2026-09-30），近一月无提交——**刚开源即冷却，需持续观察**
- 一句话定位：把真实 Windows 桌面当作二维物理世界的双角色 WPF 桌宠——任务栏和窗口是地形，窗口是容器和抛射物，回收站是食堂；纯本地、零 AI 模型。
- 架构要点（桌面物理系统的实现方式，优先级 3）：
  - **地形层**：普通应用窗口顶边、任务栏、显示器工作区被建模为"可行走/可落脚地形"；每块显示器独立计算物理像素地形，支持负坐标、跨屏窗口分段、Per-Monitor V2 DPI、工作区变化监听。
  - **窗口实体碰撞**：持续跟踪普通可见窗口的"实体边缘"，左右边缘扫过角色身体时按撞击方向 + 窗口速度施加抛飞冲量（窗口是被拖动的刚体）。
  - **移动平台惯性**：窗口快速上移会把角色抛起，窗沿追上脚底时再次顶起；向下拖动产生短暂惯性脱离并落回实时窗沿（不粘脚）。
  - **窗口容器**：把角色放进窗口内部后四壁成为封闭容器，角色保留惯性、受重力，相对移动的墙壁反弹；容器内禁用舔图标，删除事件会让她主动跑出去进食。
  - **窗沿行为集**：攀爬、下滑、跳跃到下一层、最大化时向外弹飞。
  - **拖拽手势释放**：采样松手前约 140 ms 的鼠标末速度，区分轻放/横甩/上抛/斜甩，给出不同释放速度、重力与软弹；二维惯性 + 空气阻力 + 显示器边界软弹。
  - **窗口捣蛋（菲比）**：踢/打/冲撞/帽子收藏真实移动窗口；大招只变形内存中的窗口快照（应用保持最小化、任务栏入口保留、不关进程），碎片收进帽子，**永不自动恢复**，用户右键"把窗口还回来"；切角/退出/锁屏/显示变化时安全归还；全屏和硬件加速覆盖层按窗口身份排除。
  - **回收站进食**：删除前记录桌面项目显示名 + 物理坐标；文件进入回收站（文件系统事件 + 回收站元数据按原名匹配）后糯糯跑到原位置进食；队列最多 24 份、逐份处理、被拖拽打断的目标回队首；只读元数据、不读文件内容、不替用户删/恢复。
  - **工程质量**：`Core/`（状态机、物理、行为策略）与 `Interop/`（Win32）分层；配套无界面 LogicTests 项目，物理、巡游、进食、角色隔离、捣蛋冷却、动画事件均有自动化测试。
- UI/交互模式：透明无边框置顶 WPF 窗口；非角色区域 Win32 命中测试透传鼠标；托盘菜单集中所有设置（60%–200% 实时缩放保持脚底锚点和碰撞比例）；生活状态（饥饿/饱腹/困倦/好奇）驱动状态机（待机/巡游/攀爬/坠落/着陆/睡眠），离线时长按上限继续演化；双宠共存、捏脸、本地语音带优先级 + 场景冷却 + 防重复。
- 对凌凌的启示：
  - **照抄**：①窗口交互五分类——平台 / 移动平台惯性 / 侧撞抛飞 / 封闭容器 / 窗沿行为集，可直接作为我们 rigid-body 世界窗口物理的设计清单（我们目前主要覆盖推拉踢，容器和移动平台惯性是缺口）；②手势释放 140 ms 末速度采样（手感关键）；③回收站进食 = 文件事件驱动的喂食机制 + 队列/打断回队设计，天然适配我们的饥饿 vital 与 impulse organ；④物理逻辑与渲染分离 + 无界面单测（他们 217 项逻辑测试跑物理回归，值得学）。
  - **改造**：他们的窗口破坏是"快照 cosmetic 毁坏 + 手动恢复"；我们可用同一套边界（最小化而非关闭、快照不落盘、用户手动归还）接上我们 emotion→temperature 与 HP 系统，把"捣蛋条"升级为情绪后果；我们的 gravity/FOV 相机是它没有的维度（它无相机概念），可加视差与镜头跟随形成差异化。
  - **避开**：①纯 Win32/WPF 单平台路径（我们是 Tauri/Web 栈，取算法不取实现）；②窗口永不自动恢复的激进设计（投诉风险，我们应有冷静期自动归还选项）；③其代码与素材均不可商业复用（PolyForm + 素材授权未清），只学设计。
