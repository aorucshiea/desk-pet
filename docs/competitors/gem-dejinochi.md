# 💎 Dejinochi（会离巢的桌宠）
- 出处：https://store.steampowered.com/app/5277000/Dejinochi/ · 热度：Steam 新品（2026-11-13 发售，Demo 可下，支持创意工坊 Mod） · 平台/栈：Windows 10 / OpenGL 3.3
- 一个词的特殊机制：离巢与回访 —— 宠物养大后离开你的桌面"去外面的世界"，进相册；老朋友会回来串门
- 它怎么实现的：孵化蛋→喂食/玩耍/清便/喂药，成长形态取决于照顾方式（"有些需要更多关注，你永远不知道会养出谁"）；长大后 move out，相册留存记录，此后旧宠物随机回访打招呼，你再孵新蛋开始新循环。离巢后是否携带状态回访、回访频率等细节未公开。名字即 Dejinochi = Deji(数字) + inochi(命)。
- 为什么有趣：情绪/生命感 —— 把生命周期终点从"死亡/重置"改成"毕业+探访"：失去是常态但关系不归零，相册是纪念馆而非坟场；对长期陪伴产品是极优雅的轮替设计。
- 对凌凌的启示：改造 —— 生命轮顶层加"世代"叙事：凌凌可"成年离巢"（归档为回访态，偶尔出现说"我路过看看你"），新个体从蛋开始；台账即相册。
- 可验证性：高
