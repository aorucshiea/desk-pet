# 💎 Taskbar Slime ～片隅のテラリウム～
- 出处：https://store.steampowered.com/app/5124010/ （资讯页：https://ku.gamersky.com/2026/taskbar-slime-tucked-away-terrarium/ ） · 热度：Steam 新品（2026-09-30 发售，无星小作工作室 GarrAtelier） · 平台/栈：Windows / DirectX 11
- 一个词的特殊机制：任务栏生态瓶 —— 史莱姆在任务栏角落增殖、互相融合、变异出"你没见过的东西"，玩家是填图鉴的炼金术士
- 它怎么实现的：桌宠即收纳在任务栏里的微型饲养箱；史莱姆自主增殖（multiply）与融合（merge），融合/变异结果不可预知、持续产生新形态；玩家的唯一职责是观察并在图鉴（codex）中记录。实现细节（融合规则是否遗传/随机）未公开。
- 为什么有趣：生命感/内容 —— 两点反常：把栖息地压进任务栏这条"家具缝"（空间越小越像同居），以及以"不可预知的变异+图鉴收集"替代"照护数值"，宠物会自己长成主人没见过的样子。
- 对凌凌的启示：改造 —— 生命轮加"繁衍/融合"事件：两个器官状态组合可触发非预设计的小变异形态（图鉴驱动收集欲）；或做一个"任务栏缩驻"形态（凌凌变小住在任务栏角落）。
- 可验证性：高
