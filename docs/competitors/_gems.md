## Top 5 一句话理由

1. **dsh-fish-dream** — 全场唯一"零成本、零模型、完全可解释"的做梦实现，且直接吃凌凌已有的台账事件流，可一周落地。
2. **FishPet** — 用"小模型观察者+大模型嘴替"的分脑方案解决了 LLM 宠物最大的破绽（每轮情绪清零、像刚认识你）。
3. **HippoCortex** — 首个把"睡觉"做成记忆 GC（修剪+强化+做梦）并配突触热力图面板的桌宠，与生命轮夜间阶段天然对齐。
4. **zerogochi** — JUDGE 按钮证明"宠物对主人的评价"可以是引用事实的正式产出物，给台账一个高情绪价值的消费出口。
5. **Clanker** — 心理护甲（resilience 随经历增厚）是全新的器官参数：同样一句话，旧伤累累的凌凌该"不疼了"。

## 分流

### 映射到已有系统（可改造落地）
- **FishPet → 器官 + 快直觉**：情绪值全部加半衰期阻尼；快直觉前加小模型观察层，输出（理解/心里话/情绪延续标记）三件套；精力并入电量血量。
- **SwarmWatch → 快直觉**：凌凌承接工具执行时加"守卫动作"清单，撞上即冻结并变身"求批准"形态，等主人点头。
- **Taskbar Slime → 刚体 + 生命轮**：任务栏缩驻形态；两个器官状态组合触发非预设计的小变异事件。
- **Unstable Pet → 生命轮**：照护缺口映射为习性变异（长期不互动→"野性化"会自己翻文件），而非单纯掉血。
- **Dejinochi → 生命轮 + 台账**：成年"离巢"归档为回访态，偶尔出现说"我路过看看你"；台账即相册。

### 需要新器官
- **梦种子器官**（dsh-fish-dream）：事件碎片抽取器 + 六种梦理论模板库；沉默越久触发概率越高，醒来用快直觉讲"我梦见…"，梦入记忆不入成长台账。
- **突触图谱器官**（HippoCortex）：记忆关联图 + 夜间修剪/强化批处理 + 热力图可视化 + 空闲"走神"联想。
- **判官器官**（zerogochi）：被要求"评价主人"时必须引用台账具体事件句，输出带立场的小判决，不可凭空。
- **护甲系数 + 归因链**（Clanker）：同类情绪刺激敏感度衰减；器官数值变化保留"是哪句话造成的"可点开归因。
- **发育形态系统**（FlyMuse）：外观/姿态成为器官状态的实时函数，且随相处时长漂移——北极星级目标，仅记录方向。
