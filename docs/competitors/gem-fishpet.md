# 💎 FishPet（大肥鱼桌宠 / fishpet-release）
- 出处：https://github.com/ygc06/fishpet-release · 热度：无星小作 · 平台/栈：Windows 一键安装包 + DSH 插件联动，Live2D
- 一个词的特殊机制：情绪惯性 —— 小模型当"内心观察者"、大模型当"嘴"，情绪跨轮次有阻尼不会瞬间清零
- 它怎么实现的：小模型负责记录"她怎么理解这句话、心里在想什么、这轮情绪有没有沿着上一轮走"；大模型拿到这些观察结果再决定嘴硬、撒娇、吃醋还是认真哄你。情绪有惯性：被惹生气不会因为下一句换个标签就立刻笑着原谅，刚被哄到一半也不会马上把委屈收回去。表情跟着情绪与精力走：精力低眼皮耷拉、真累坏了闭眼睡着。当前心事、还没说完的话、长期记住的事分层持久化，不会被下一轮回复冲掉。
- 为什么有趣：情绪/技术 —— "记仇但不记死账"的时间维度情绪，是连续心智（不是每轮都像刚认识你）的最小可行实现。
- 对凌凌的启示：改造 —— 在快直觉前加一层小模型观察者，输出（理解、心里话、情绪延续标记）三件套；器官情绪值全部加半衰期阻尼，禁止单轮清零；精力直接并入电量血量。
- 可验证性：高
