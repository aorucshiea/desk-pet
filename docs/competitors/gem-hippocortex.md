# 💎 HippoCortex（类脑 AI 桌宠助手）
- 出处：https://pypi.org/project/dyao-hippocortex/ · 热度：无星小作（PyPI 开源） · 平台/栈：Python 3.11 + Ollama（gemma3:4b + bge-m3 向量）
- 一个词的特殊机制：睡眠巩固 —— 海马体-皮层分工架构，"睡觉"= 修剪突触 + 强化核心记忆 + 生成梦境的批处理
- 它怎么实现的：模拟人脑海马体-皮层分工，多专家分区处理不同类型知识；记忆分级为 短期→长期→永久，带自然遗忘与睡眠巩固（自动修剪无效突触、强化核心记忆、生成梦境）；赫布学习"共同激活、连接强化"让越用越聪明；空闲时自主读书学习、进入"走神"状态做回忆与联想；脑状态可视化实时显示疲劳度、记忆数、突触连接热力图。点击"睡眠"按钮即触发巩固。
- 为什么有趣：技术/生命感 —— 把"睡觉"从停机变成功能：遗忘（修剪）、巩固（强化）、做梦三合一，还配突触热力图当器官面板。
- 对凌凌的启示：改造 —— 生命轮夜间阶段跑一次"记忆修剪与强化"批处理；把"走神"做成空闲低耗器官（从台账随机联想旧记忆）；给器官面板加一张关联/突触热力图。
- 可验证性：高
