# 💎 Unstable Pet
- 出处：https://itch.io/jam/do-you-wanna-jam-2026/rate/4924153 · 热度：无星小作（"Do you WANNA Jam?! 2026" 参赛，48 评分） · 平台/栈：itch.io 桌宠养成游戏，未开源
- 一个词的特殊机制：逆向养成悖论 —— 对它越差，进化越强、但带缺陷
- 它怎么实现的：作者在 jam 评分页自述对主题 "UNSTABLE" 的诠释：一旦过度喂食/清洁/关爱/忽视，宠物的进化就变得不稳定——进化形态更强大但带有缺陷（"The evolution is more powerful but has a defect"）。即把 tamagotchi 的照护数值（喂食/清洁/爱心/忽视）反向接入进化分支树。具体代码与分支表未公开。
- 为什么有趣：情绪/内容 —— 把"做完美主人"的默认契约倒过来，制造道德拉扯：想变强就得狠心，想干净就得平庸；给二周目一个理由。
- 对凌凌的启示：仅记录/改造 —— 不做"虐待奖励"，但可做低成本旁支：生命轮的照护缺口映射到外观/习性变异（如长期不互动 → 学会自己翻文件觅食的"野性化"缺陷形态，而不是单纯掉血）。
